# 前置诊断样本，不纳入正式延迟统计

这批试跑使用了同时包含目标和权限要求、但标为 `outcome` 的基准输入，触发了“特殊输入不能修改其它 Mission 分区”等输入合同问题。它没有验证成功的提交到执行链路，不能用来推断正常任务的性能或选择分段参数。正式基准已改用 `information` 承载完整要求。

初版 observer 的受理上界还包含监督器启动时间，阶段数据未区分提交前的完整索引准备；后续版本已分别修正。现有原始文件只用于诊断，保留原样，不与正式结果混合。汇总器将旧预热阶段标为 `unclassified`，并拒绝混合 observer 版本或模型／预算配置。

`interrupted-cold-1.json` 跨越了长时间中断，其观察时长约 7.45 小时，不能进入本轮延迟分位数，原位置的 repeat=1 已重新测量。新版会将超过截止窗口的里程碑单独保留为审计值，排除出分位数。
